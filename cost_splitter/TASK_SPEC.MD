Создайте небольшое браузерное приложение «Делим счёт».

## goal
Пользователь вводит:
* сумму счёта;
* количество человек;
* процент чаевых.

Приложение показывает:
* итоговую сумму с чаевыми;
* сколько должен заплатить каждый человек.
* пустые и некорректные значения должны обрабатываться.

## scope
* HTML + CSS + JavaScript;
* страница должна работать локально;

Если сумма не делится поровну до копейки, приложение должно корректно распределить остаток.

## non-goals
Ограничения:
* без backend;
* без фреймворков;

## критерии приёмки
* страница отображается
* Сумма счета корректно делится между пользователями
* если сумма не делится на количество пользователей, то она распределяется межу пользователями в неравных, но минимальных долях. Например 10 / 3 = 3.34 + 3.33 + 3.33
Перед реализацией создайте `TASK_SPEC.md` с goal, scope, non-goals, критериями приёмки и планом проверки.
