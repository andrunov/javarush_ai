## Цель и желаемый результат
Интерактивная симуляция в формате 8-бит, работающая в браузере.
Основана на задаче «100 заключённых и 100 ящиков» — вероятностный парадокс про стратегию поиска:
100 пронумерованных заключённых и 100 ящиков, где их номера разложены случайно;
каждому можно открыть лишь половину ящиков и найти внутри свой номер — и спастись должны все разом;
стоит ошибиться одному, проигрывают все.

## Границы задачи (scope и non-goals)
Работает в браузере, без установки.
Одна страница. По горизонтали — три части без видимых границ-линий, **слева направо**:
1. Матрица заключённых (10×10) — человечки с номерами, ожидающие хода.
2. Матрица коробок (10×10) — коробки с номерами-наклейками.
3. Матрица заключённых, прошедших коробки (10×10) — то же, что пункт 1; заполняется постепенно.

По вертикали страница разделена чертой в соотношении 95/5. В верхней части — описанные матрицы.
Нижняя часть, слева направо:
1. Выбор стратегии (radio, ровно одна).
2. Ползунок скорости (1–50 ящиков/сек, по умолчанию 25).
3. Кнопка «Refresh boxes» — новая случайная раскладка коробок.
4. Кнопка «Start».
5. Кнопка «Skip» — мгновенно доводит текущий раунд до результата без анимации.
6. Надпись о результате и кнопка «Restart». При первом запуске пусто; после раунда — «Success!» или «Fail» и «Restart».

## Non-goals: без бэкенда, без фреймворков, без звука (v1), без режима мгновенного турнира/статистики, **не накапливаем и не храним историю результатов**.

## Игровой процесс (детали)
- **Раскладка**: номера внутри коробок — случайная перестановка 1..100. Новую раскладку даёт «Refresh boxes».
- За один раунд играется **одна выбранная стратегия**. Сравнение стратегий пользователь делает вручную: сменить стратегию + «Start».
- Заключённые ходят по порядку номеров: 1, 2, …, 100.
- **Стратегии**:
  1. «Случайный» — открывает 50 разных случайных коробок (без повторов).
  2. «По цепочкам» (стратегия из видео) — начинает с коробки со своим номером, далее идёт к коробке, чей номер нашёл.
  3. «Первые 50» — открывает коробки 1..50 подряд (наивная, для контраста).
- Внутренние номера коробок видны зрителю только в момент открытия. Для каждого нового заключённого коробки закрываются заново.
- Заключённый покидает коробки сразу, как только нашёл свой номер (не обязательно открыв все 50).
- Если заключённый не нашёл свой номер за 50 коробок — раунд сразу останавливается: «Fail», провалившийся заключённый подсвечивается.
- Если все 100 нашли — «Success!».
- Текущий заключённый подсвечивается; рядом с матрицами подпись «Prisoner N · Стратегия: …».
- Результат показывает итог только текущего раунда.
