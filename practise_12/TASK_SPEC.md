## Границы задачи (scope и non-goals)
Работает в браузере, без установки. Для тестирования доступно 10 и более стратегий (не более 30)
Одна страница. Шапка страницы - три элемента настроек теста, слева направо:
1. Выпадающий список, где можно выбрать стратегию для тестирования. Заголовок - "Выбарите стратегию"
2. Выпадающий список с заголовком "Количество шагов". Доступные для выбора пункты: 5, 10, 50, 100, и "Неизвестно заранее"
3. Чекбокс "добавить ошибки"
4. Кнопка "Start"
Ниже начинается таблица, которая занимает всю оставшуюся страницу. 
Строки таблицы представляют собой другие стратегии - как они будут вести себя при взаимодействии с тестируемой стратегией, 
выбранной в чекбоксе. Столбцы таблицы - это шаги. Одна ячейка - один шаг. Каждая ячейка разделена на две по вертикали - для выбранной стратегии и стратегии - оппонента. 
Заголовки строк (самый левый столбец) - наименования стратегий. 
Содержание ячеек заполняется цветом - красным или зеленым, в зависимости от выбора стратегии (предать или сотрудничать соответственно), и числом - заработанные очки
Самый правый столбец - сумма тестируемой стратегии и стратегии - оппонента.
Подвал страницы - выводится чемпион - стратегия, набравшая наибольшее количество очков. 
Результаты тестирования стратегий помнятся в течение сессии 

## Non-goals: без бэкенда, без фреймворков, без звука (v1), без режима мгновенного турнира/статистики, **не накапливаем и не храним историю результатов**.

## Игровой процесс (детали)
- Пользователь выбирает стратегию для тестирования
- Пользователь выбирает количество шагов 
- Пользователь выбирает наличие встроенной ошибки
- Пользователь запускает процесс тестироания кнопкой "Start"
- В таблице происходит анимация взаимодействия стратегий со скоростью 5 шагов в секунду
- При этом правый столбец с итоговыми суммами заполняется в реальном времени
- Строки таблицы сортируются по убыванию в реальном времени по значению суммы в итоговом (правом столбце) для тестируемой стратегии (не для ее оппонента) 
- Если стратегия стала чемпионом, и если это не первый раз за сессию, на страницу выводится анимированный салют и надпись "Ура!" или еще какое-нибудь восклицание, например "Bingo!"

7. Проверка в 2 браузерах: контроль что «Око за око» побеждает чаще других.
